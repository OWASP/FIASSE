## Project Identity Memory

- FIASSE = Framework for Integrating Application Security into Software Engineering.
- FIASSE is pronounced like "phase" (per README).
- SSEM = Securable Software Engineering Model.
- Use "SSEM" as an acronym in writing and speech (say the letters S-S-E-M).

## Positioning Rules

- FIASSE is a creational framework targeted at developers and software engineering practice.
- Do not position FIASSE as a security assurance mapping framework.
- Do not describe FIASSE as a replacement for assurance frameworks such as ASVS or SAMM.
- Prefer language that frames FIASSE as complementary to assurance and verification approaches.

## Writing and Contribution Guardrails

- Keep language developer-centric and practical.
- Emphasize securable qualities and software engineering attributes.
- Avoid adversarial, exploit-centric framing when describing expected developer behavior.
- Prefer positive, prescriptive guidance (what to build in) over block-list style guidance (what to avoid).
- Do not use dashes as sentence structure to connect full ideas.
- If a sentence feels overloaded or compound, rewrite it as two or more clear sentences.
